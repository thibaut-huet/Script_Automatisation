# SCRIPT AUTOMATISATION 

Ce repository regroupe les différents scripts et manipulations effectués pour automatiser des tâches en milieu professionel.   


## Les différents scripts :
+ Script python pour effectuer un transfère d'inventaire dans un fichier Excel avec menu déroulant.
+ Script Powershell pour le déploiment automatique d'un banière particulière Excel et d'une licence PDFxchange.  
+ Script Powershell déployé sur Intune pour répertorier tout les écrans connectés aux PC collaborateurs et leurs associer dans l'inventaire.
